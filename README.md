# agent/agent

A thin aux4 wrapper over `aux4 ai agent ask`: a self-directed agent composed from an immutable base discipline, optional `AGENTS.md` domain instructions, `config.yaml` identity/model, and on-demand skills. Runs headless with a cron heartbeat and per-conversation history.
